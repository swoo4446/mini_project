- G-4 자동 복구 실패·원인 불명 시 상태 보존과 에스컬레이션
- G-5 필수 테스트 실패 시 배포 차단

성공 기준 SC-1~SC-9를 Day 3 실험 결과로 증명한다.

## 3. 작업 원칙

1. PRD v1.0이 유일한 요구사항 기준이다. PRD에 없는 기능은 추가하지 않는다.
2. 각 기능 작업은 `실패 테스트·검증 조건 → 최소 구현 → 단위 테스트 → 통합 확인 → 완료 증거` 순서로 수행한다.
3. "코드 작성"은 완료 기준이 아니다. 테스트 통과, 상태 전이, API 응답, 로그, 지표 등 실행 증거가 있어야 완료로 표시한다.
4. 정상 흐름과 기준선을 장애 주입보다 먼저 확보한다.
5. 재시작·비용 발생·사람 승인 흐름은 별도 하위 작업과 안전 검증을 둔다.
6. 장애 실험은 모의 의존 서비스와 실습 전용 환경에서만 수행한다.
7. LLM 에이전트는 MVP에서 고정 응답(모의 주문 해석 서비스)으로 동작한다.
8. 정책 수치는 `config/healing_policy.yaml` 한곳에서 관리하고 코드에 직접 쓰지 않는다.
